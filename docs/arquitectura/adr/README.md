# Decisiones de arquitectura (ADR)

Los ADR registran decisiones de diseño, su estado, evidencia y consecuencias. Una propuesta no equivale a una decisión aprobada. Para añadir uno, usa el siguiente número disponible y enlázalo aquí.

| ID | Decisión | Estado |
|---|---|---|
| [ADR-001](001-evidencias-y-firmas.md) | Evidencias y firmas en ciclos de esterilización | Propuesta para decisión del negocio |
| [ADR-002](002-pdf-playwright-nextjs.md) | Renderizado de PDFs con Playwright y Next.js | Aceptado; implementado |
| [ADR-003](003-consecutivos-transaccionales.md) | Consecutivos transaccionales con bloqueo pesimista en base de datos | Aceptado para cotizaciones y certificados |
| [ADR-004](004-rbac-con-ambitos.md) | Permisos centrales y múltiples roles por ámbito | Aceptado; fundamentos implementados, activación pendiente |

Los documentos de este índice describen el código del repositorio. La disponibilidad y configuración de los ambientes desplegados se valida por separado.
